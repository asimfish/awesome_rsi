## 决策
- 2026-09-15：用户选择“RSI 优化芯片设计”，优先优化实际电路。
- 首个目标：verilog-axis MIT priority_encoder，固定 WIDTH=64、MSB 高优先级，保留全部输出包括零输入行为。
- 候选只改变 RTL，验证器、参考和约束固定；经验是文本策略，不更新模型权重。
- 评价：Nangate45 TT 1.1 V / 25°C，20 ps 输入转换，5 fF 输出负载；Yosys/ABC 映射后 OpenSTA 延迟。无寄生、无布线、无功耗测量。
- 预算：6 次候选生成 + 每轮最多 1 次经验提炼（至多 12 次 API 请求），单请求最多 6000/600 输出 token；单 EDA 阶段墙钟 110 秒、CPU 90 秒、内存 3 GiB。
- 晋升：形式通过且 ADP 比当前优胜至少低 1%，延迟 ≤ 原始基线的 105%。
- 本轮不能证明 RSI 相对无记忆搜索的因果优势；后续跨模块和消融需要另行实验。
