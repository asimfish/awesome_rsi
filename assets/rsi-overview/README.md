# RSI 综述图

`overview.png` 用于网站首页与全景综述页。`prompt.txt` 为初始生成提示词，`repair-prompt.txt` 为背景与对比度修正提示词。

## 方法与来源

- 使用 [super_teaser](https://github.com/asimfish/super_teaser) 的源证据约束、机制构图与箭头语义检查方法，参考版本 `6b1d41b0b81ed09ed5cd692182ae05fc5573ac12`。
- 本次为用户要求的单张跨论文综述图，采用单图生成与一次修正；未执行或声称完成该工具的完整 S0–S5 多候选交互流程。
- 图像由内置 `image_gen` 生成；修正仍使用同一图像工具，无程序化绘图替代。
- 科学内容来自 `website/overview.md`：第 1–2 节支持递归定义与五种修改对象；第 3–4 节支持候选验证与独立评估；第 5 节支持字节三篇的并列问题；第 6–8 节支持版本保留与尚待验证的持续改进能力。

## 语义边界与检查

- 主循环是综述的概念归纳，不表示任何一篇论文实现了所有环节。
- 五种修改对象为并列选项，不是必须依次执行的步骤。
- 独立评估依据位于候选修改循环之外，仅指向候选检验。
- 通过验证的候选进入保留版本；拒绝分支不进入保留版本。
- Aspire、S³Gym、HarnessDev 是并列研究问题，不构成流水线。
- 未使用跨论文数值排名、伪造实验曲线或已实现无限递归的表述。
- 首版背景出现暗色光斑，已通过图像编辑修正。最终图已检查中文标签、箭头方向和证据边界；网页提供原图入口与文字替代说明。
