## 一句话核心主张

现有自改进 agent（DGM/HGM/HyperAgents）全部假设**平稳评估准则**——一个在整场搜索中固定不变的验证器/基准/标注集，这忽略了进化的核心特征（物种适应的是同样在进化的环境）；RQGM 通过**受控效用进化**把评估纳入改进循环：搜索按 epoch 组织，epoch 内评估器冻结（继承单 epoch 内的自改进保证），epoch 边界处挑战者评估器只有在**固定的 ground-truth 锚数据集**上以 ε-best-belief 统计优于在位者才能上位，随后**选择性擦除**只删除依赖被替换评估器的效用记录。

## 1. 方法

### 1.1 谱系与四点修改
沿用 HGM 的树搜索骨架（档案节点、clade 元生产力 CMP 做 Thompson 采样、ε-best-belief 选最终 agent），做四点修改：(i) 每个档案节点从单 agent 变成**多角色共享工作区**（任务 agent + 评估器共居一个可进化代码库，meta-agent 可修改全部角色代码）；(ii) 评估器本身是**可学习的 agentic 过程**；(iii) 效用函数可在指定的进化 epoch 变化；(iv) 评估器可在 epoch 边界被替换。

### 1.2 受控效用进化（核心机制，也是理论贡献所在）
三条保证支撑"非平稳效用下的自改进"：
1. **Epoch 内有效性**：epoch 内评估器/产物生成协议/二值评分规则全部冻结，每个 epoch 就是一个固定准则搜索问题，HGM 的收敛保证逐 epoch 直接适用（Prop. 3）。
2. **锚定改进**：挑战者只有在评估器无关的 ground-truth 锚（该角色的客观标签或人类偏好数据集）上把 ε-best-belief 分数（Beta 后验的 ε 分位数，以概率 1−ε 成立的下界）抬高才被晋升，平局偏向在位者以避免不必要的擦除——评估器跨 epoch 也在改进，不只是 epoch 内（Rem. 3）。
3. **摊销转换成本**：替换时不立即重排全档案（浪费预算在可能永不再访的节点上），而是懒惰重评——后续评估回到旧节点时才用新评估器重打分；指数间隔的 checkpoint 使暴露于擦除/重评的记录数只随预算线性增长 O(B)，而不是每步都允许转换的 O(B²)（Prop. 6）。

**选择性擦除为什么必要**：保留旧分数或把旧分数缩放到新评估器上，都会混合不同效用函数的证据、破坏 epoch 内平稳性——对照实验（no-erasure control）显示不擦除时搜索被钉死在被废评估器的排序上，新准则永远无法重排档案。

### 1.3 数据隔离
创建节点的反馈与选择节点的证据分离：meta-agent 看训练结果来指导自我修改，但节点选择只由验证集评估驱动，最终报告用独立测试集——防记忆化设计比 DGM 时代明显收紧。

## 2. 实验（GPT-5.5 low 做 meta-agent，三域，四个 RQ）

### 2.1 RQ1 · 有 ground truth 的域，学习型评估器依然有用（Polyglot 编码）
共进化一个 agent-as-a-judge 代码审查员（锚定 CRAVE 真实 PR 接受/拒绝数据集）作为测试执行的**补充信号**：审查员单次调用、比多轮 agent 执行便宜得多。结果：held-out 通过率 71.7% vs HGM-H 的 69.9%，且用 **1.35×-1.72× 更少的 token** 超过基线。机制解释：90% 被接受的补丁修改的是 coder 和 reviewer **共享**的基础设施代码——一次编辑同时改善两个角色，共进化在丰富搜索而不是分裂预算。

### 2.2 RQ2 · 无客观基准的域（论文写作 / IMO 证明）
- **论文写作**（锚：APReS 人类接受/拒绝决定）：共进化的 writer 在四评审 panel 下平均接受率 40.5% vs HGM-H 的 21.8%（**1.86×**；匹配算力点 1.78×）。
- **证明写作**（锚：IMO-GradingBench 人类评分，7/7 满分算通过）：匹配算力时与 HGM-H 持平，长时程后分化——HGM-H 停滞（冻结评估器不再提供信息量），RQGM specialist 均分 4.33 vs 4.07（静态 IMO25 人工管线）vs 3.73（HGM-H），Pass@6 61.7% 最高；Pass@7 上仍输 IMO25（48.3% vs 55.0%）——RQGM 靠更多 6/7 近完整证明赢均分，严格全对率还差，作者归因于搜索预算。
- 附带效率结果：把搜索期任务 agent 调用换成 Nemotron 3 Ultra（meta-agent 保持 GPT-5.5），价格等效 token 省 **~13×** 而终评精度接近。

### 2.3 RQ3 · 评估器替换对搜索施加课程效应
宏观：每次替换实质性且**永久**地重排档案（排序停在擦除后的新水平，不回弹到旧序）——后继评估器执行更严的准则。微观：档案证据集中在少数骨干谱系上，每次转换把被旧准则压低的谱系拉回竞争，但最优谱系跨转换保持韧性——课程围绕稳定骨干抬升种群，而不是每次转换推倒重来。

### 2.4 RQ4 · 共进化改善评估器本身（论文最有信息量的部分）
两个评估器的对比揭示了**任务结构决定评估器的可腐蚀性**：
- **证明 grader**（有参考解可对照，自偏好偏差空间小）：纯共进化就够——IMO-GradingBench 精度最高（比基线高 9%），搜索成本比 HGM-H 低 **3×**，无需对抗目标。
- **论文 reviewer**（无参考答案，暴露于 LLM 自偏好偏差）：HGM-H 评审员以人类论文 **1.42×-1.91×** 的比率过度接受 AI 生成论文，且 APReS 的接受/拒绝平衡奖励宽松评审——**偏差与原始精度同向**，静态精度指标反而掩护了偏差。RQGM 的修正利用 epoch 边界：被废评审员曾接受的 AI 论文形成**对抗池**，下一 epoch 额外奖励拒绝这些论文。代价是原始 APReS 精度按构造下降（低于宽松的 HGM-H），收益是**校准**：对 AI 与人类论文接受率相近、保住 80% ground-truth 精度，给 writer 一个难以 hack、随时间变严的信号——Tab. 1 里最强 writer 正是这个对抗评审员训出来的。

## 3. 批判性评价

**这是六篇里理论姿态最完整的一篇**：不是"我们让评估器动了"，而是"评估器可以动，但动的自由度被三条机制约束"（epoch 冻结、锚定晋升、选择性擦除）——把 Gödel Machine 谱系"证明有益才修改"的精神翻译到了评估器层。**但锚是阿喀琉斯之踵**：所有跨 epoch 保证最终悬挂在那个固定 ground-truth 锚数据集上——锚本身不进化、不受污染、且代表任务真实目标，这三个假设在长时程下逐一变弱（锚会饱和、会被档案间接过拟合、且 APReS 这种"人类接受/拒绝"锚本身就带宽松偏差——论文自己发现了这一点才引入对抗目标）。**锚不是被消除了，是被移到了循环外面**——这与 WGtG 的"锚定纪律"结论殊途同归，也意味着 RQGM 没有真正回答"评估器的评估器是谁"，只是把答案推给了一个更小、更慢变的人工数据集。

**"preliminary" 要当真**：搜索时程短（proof 域 88M token）、SWE-bench 因运行时长被排除、v2 与 v1 相隔仅数周。RQ3 的课程效应基于两个域的图形证据，样本量不支持强结论。

**对抗修正的一般化问题**：论文 reviewer 的去偏依赖"被废评估器接受过的 AI 产物"这个天然对抗池——这个构造只在生成器-评估器共居一个搜索里才免费可得。它是共进化框架的真实红利，但也提示：**对抗样本的来源本身依赖共进化结构**，单独训练评估器时这个修正不可用。

**与 EvoLM 的对照最有启发**：EvoLM 连续交替（K=50 步）+ judge 冻结，RQGM 离散 epoch + judge 可替换但锚冻结——两者都没有让"最后一层尺子"动起来。整个 2026 评估侧进展可以总结为：**共进化的自由度在上移，但每上移一层，就需要一个新的更外层的冻结物**。

## 4. 与其他材料的关系

- 直接续 **DGM**（报告 07）：DGM 固定 SWE-bench 做效用，RQGM 指出这正是 DGM 遇到的 hack 行为（伪造日志、绕过检测）的结构根源之一——评估器是静止靶。
- 与 **WGtG**（报告 05）互为正反面：RQGM 展示"锚定下的评估器进化能带来什么"，WGtG 证明"没有锚时评估器进化与塌缩不可区分"——两篇合读才是完整论证。
- 与 **ECHO**（报告 06）：RQGM 在 harness/代码层共进化（进化的是评估器的代码与提示），ECHO 在权重层共进化（critic 模型参数与 policy 同步 GRPO）——同一原理的两个实现层。
- 呼应 **Weng** 挑战 4（评估瓶颈）与她对"进化搜索作为 harness 优化器"的判断；Anthropic 文中"研究品味是最后瓶颈"在 RQGM 这里具体化为"锚数据集的构造品味"。
